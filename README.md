# GLX-Radio for Nextcloud

**GLX-Radio** is a custom Nextcloud application designed to bring seamless internet radio streaming directly to your personal cloud environment. Featuring a clean, modern Vue.js frontend and a robust PHP backend, it integrates smoothly into your daily workflow.

## Features
- **Live Stream Proxy:** Securely stream internet radio stations with built-in proxy handling to avoid mixed-content issues.
- **Favorites Management:** Save and quickly access your preferred radio stations.
- **Custom Settings:** Easily manage your streaming preferences and configurations.
- **Modern UI:** Built with Vue.js for a responsive and intuitive user experience.

## Requirements
- Nextcloud (compatible with recent major versions)
- PHP 8.0 or higher

## Installation
1. Clone or download this repository into your Nextcloud `apps/` directory (ensuring the folder is named `glxradio`).
2. Enable the app through the Nextcloud Administrator panel.
